# Jadwal.in 📅

Platform perencanaan jadwal dan onboarding modern berbasis web.

## 🚀 Tech Stack

- **Framework**: [Astro](https://astro.build/)
- **Typography**: Plus Jakarta Sans
- **Styling**: Modern Vanilla CSS with Responsive Design

## 🛠️ Menjalankan Proyek

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Jalankan local development server:**
   ```bash
   npm run dev
   ```
   Buka [http://localhost:4321](http://localhost:4321) di browser.

3. **Build untuk production:**
   ```bash
   npm run build
   ```
